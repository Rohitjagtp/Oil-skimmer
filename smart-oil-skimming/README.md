# Smart Oil Skimming System — Website

Smart India Hackathon 2026 · Team Innovation

A static, front-end website presenting the Smart Oil Skimming System: an
automated oil-skimming system that removes floating oil from industrial
coolant/wastewater, senses oil level, and adjusts belt speed automatically —
with a live-style monitoring dashboard.

## Running it locally

No build step or server-side dependency is required. Any of the following works:

**Option A — just open it**
Double-click `index.html` to open it directly in a browser.

**Option B — local server (recommended, avoids any browser file:// restrictions)**
```bash
cd smart-oil-skimming
python3 -m http.server 8000
```
Then open `http://localhost:8000` in a browser.

## About the dashboard data — read this

**No physical hardware is connected.** Every value shown on `dashboard.html`
is generated by `data/sensor-data.js`, which is clearly labelled
`DEMO / SIMULATED DATA` in the UI itself.

### Connecting real ESP32 hardware later

`data/sensor-data.js` exposes one function that the rest of the site calls:

```js
SensorData.fetchLatestReading()
```

To switch from simulated to live data, replace the body of that function
with a real network call to your Python API / ESP32 endpoint, e.g.:

```js
async function fetchLatestReading() {
  const res = await fetch('http://<esp32-or-api-host>/api/reading');
  return await res.json();
}
```

As long as the returned object has the same fields (`oilLevel`, `motorSpeed`,
`beltStatus`, `cleaningStatus`, `systemStatus`, `alertLevel`,
`oilCollectedToday`), no other file needs to change — every chart, stat card
and alert on the dashboard will start reflecting real sensor readings.

A minimal Python (Flask/FastAPI) endpoint on the ESP32 side would receive
sensor readings over serial/Wi-Fi and expose them as JSON matching that
shape.

## Customizing

- **Team details**: open `index.html`, scroll to the Team section — names,
  roles, college, department, team ID and problem statement ID are
  `contenteditable` and can be typed into directly in the browser, then
  copied into the HTML source to make them permanent.
- **Colors/fonts**: edit the `:root` variables at the top of `css/style.css`.
- **Research links**: add real reference URLs into the research list in
  `index.html` once available.
