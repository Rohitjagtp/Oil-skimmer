About This Project

Built for Smart India Hackathon 2026

This site was built by Team Innovation to present the Smart Oil Skimming System — an automated system for removing floating oil from industrial coolant and wastewater — to Smart India Hackathon judges, faculty, industry visitors and the public.

What this website is

A demonstration platform for the project: it explains the problem, the solution, how the system works, its architecture and technology, and shows a live-style monitoring dashboard driven by simulated sensor data.

What this website is not

It is not connected to physical hardware. Every number on the dashboard is clearly generated by a simulator in data/sensor-data.js, not read from a real ESP32 device.

Path to Real Hardware

How simulated data becomes live data

1. Build the physical skimmer

Conveyor belt, scraper, oil-level sensor, motor and ESP32 controller assembled per the project design.

2. Serve readings from a Python API

The ESP32 reports sensor data to a small Python backend, which exposes it over HTTP.

3. Point the dashboard at it

Replace the body of fetchLatestReading() in data/sensor-data.js with a real fetch() call — every chart keeps working unchanged.
